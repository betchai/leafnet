Model Acceptance Report

Held-out evaluation against the pre-registered Objective-4 acceptance criteria (acceptance config v2), plus per-class performance for every evaluated model version. Thresholds are fixed before training runs and are never tuned after results exist; every verdict is advisory until an expert promotes the model.

Objective 4 · accuracy, precision, recall, F1 Acceptance config v2 Dataset v1.0 · held-out test n=200 Macro bar ≥ 0.60 · per-class bar ≥ 0.40
Methodology: each model is evaluated exactly once against a class-stratified held-out test split (200 images, 50 per class) — the test set is untouched, weights are untouched, no re-tuning after results. Chart A compares each acceptance criterion's observed value with its pre-registered threshold. Chart B shows per-class precision, recall and F1 against the per-class floor of 0.40. "Worst-class" metrics are the minimum across the four classes. Field (verified feedback) values come from expert-verified application feedback and are shown for reference only.
