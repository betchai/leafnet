# Static assets

Files here are served at the site root by Vite.

## schematic.png

Drop the generated architecture diagram here as `schematic.png`.
The landing page auto-detects it and displays it in the "System architecture"
panel (falling back to the built-in SVG diagram while this file is absent).

Spec: see `docs/schematic.md` — landscape 16:9 PNG, dark background (#0f172a), ≥1600×900.
